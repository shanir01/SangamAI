Where to paste it
  1. n8n: Credentials → OpenAI → API Key + Base URL
  2. VS Code (Cline / Continue / Roo): provider "OpenAI Compatible" → Base URL + key + model auto
  3. LangChain / LlamaIndex: base_url= + api_key=
  4. Your own website or bot: use the code on the right ↓
